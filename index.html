Tournament Day Snapshot

Once rosters, pairings, and PINs are finalized for the event (or for the day), click this to generate a block of text to paste into both index.html and live.html, replacing the SNAPSHOT block near the top of each. It lets everyone's very first login load instantly from data baked into the page instead of waiting on Google — the biggest help right at the moment everyone opens the app at once. It only covers Settings/Roster/Pairings/PINs, never live scores, so nothing about mid-round play depends on this. Regenerate it once before Day 1 (after pairings for both days and all PINs are set — both days' pairings load together regardless of which day is being played), and again only if you change something in Settings/Roster/Pairings/PINs after that. An out-of-date snapshot isn't harmful — it just means that one detail briefly shows the old value on a first login before the normal live check corrects it a moment later, same as always.

Testing Mode: Suspend PIN Requirement

Turn this on temporarily while the guys are testing the app so anyone can enter scores for any match on Live Scoring without needing a PIN — handy for a dry run before real Scorekeeper PINs matter. It doesn't clear or change any match's saved PIN; it just stops Live Scoring from asking for one while this is on. Turn it back off before the tournament and every match goes back to needing its own PIN (or the Admin PIN) exactly as before.

Concede Prompt

When a match (or a Day 2 segment) becomes mathematically decided before every hole has been played, Live Scoring can offer the losing team's scorekeeper the choice to concede the rest or keep playing it out. This is ON by default. Turn it off here if you'd rather players always finish every hole and never see that prompt.

Start New Season

Once this year's tournament is over and you're ready to set up next year's: this archives everything from this season (settings, roster, pairings, scores) into hidden backup tabs in the Google Sheet, then clears pairings and scores and resets every player's team back to unassigned so you can start fresh. Player names, handicaps and tees stay as they are — no need to re-enter the roster. The Hole Handicaps table also stays as-is (only re-enter it if you're changing courses).

Roster

Add every player and which team they're on. Handicap Index and Tee are used for Day 2 net scoring — fill them in whenever you have them, they're not required to set up pairings. Course Handicap is calculated automatically from those two (Red: Slope 111 / Rating 64.1; Gold: Slope 120 / Rating 67.1; Par 72 both) and is what's actually used for strokes on scorecards and during matches — it's read-only here, just type in Handicap Index and Tee and it fills itself in. Check Scorekeeper? for every volunteer willing to keep score for their own match — once checked here, the Day 1/Day 2 Pairings tables will flag any match whose four players don't include at least one.

The number of matches on the Day 1/Day 2 Pairings tabs and the Scorekeeper PINs tab is kept in sync with this roster automatically: it's always (Team A size)/2, so adding or removing 4 players (2 per team) adds or removes one match the moment you hit Save Roster below. Growing adds a new blank match at the end for you to fill in; shrinking only removes a trailing match that has no players in it yet — if the match that would need to go still has players assigned, you'll be told to clear them first.

Scorekeeper PINs

One PIN per match number, shared by both days — a scorekeeper enters it once on Live Scoring and it unlocks that match number on Day 1 and Day 2 both. This assumes the same foursome plays match number N on both days; if a match's actual players ever differ between the two days, its one PIN still unlocks both, since there's no way to give the two days separate codes anymore. Leave a match blank to leave it open to anyone with the link. Only the scorekeeper should be told the PIN, so pass it along directly (in person, by text) rather than writing it anywhere players in general will see it — it's deliberately left off printed scorecards.

Hole Handicaps

Gold Stroke Index ranks each hole 1 (hardest) to 18 (easiest) — this is what Day 2's Live Scoring page uses to work out net scores from each player's Handicap Index on the Roster tab. Red tees play to a different Stroke Index than every other tee on this course, so there's a separate column just for them: any Roster player whose Tee is "Red" gets strokes from that column instead, everyone else (Gold, White, Blue, etc.) uses the regular Gold Stroke Index column. Par is optional, just for reference, and doesn't change by tee. This table is set once per course/tee setup and shouldn't need changing after that — if it ever does (a new course, a corrected number), edit it directly in the Google Sheet's HoleHandicaps / HoleHandicapsRed tabs rather than here.

Print Blank Scorecards

For players who'd rather write scores by hand than use Live Scoring on a phone. Prints one paper scorecard per match with the tournament name, date, tee, and hole numbers. Day 2 also shows the Gold Stroke Index and each player's handicap strokes marked as dots on the holes they apply to. Day 1 is one row per team instead of per player, since Captain's Choice and Modified Alternate Shot are both one combined score per team per hole — no handicap strokes apply, so there's no Hcp row or dots for that day. Any match printed without a Scorekeeper PIN yet automatically gets one generated and saved so scoring is still locked down on Live Scoring — but the PIN itself is never printed on the card. Check the Scorekeeper PINs tab and tell each match's scorekeeper their PIN directly.
